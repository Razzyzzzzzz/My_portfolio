# Joshua P. Deregla — Portfolio

A modern, responsive React.js portfolio website.

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

## Customization

- **Profile photo**: Replace `public/profile.jpg` with your own photo
- **GitHub/LinkedIn links**: Search for `yourusername` in the components and update
- **Projects**: Edit `src/components/Projects.jsx` to add new projects
- **Skills**: Adjust percentages in `src/components/Skills.jsx`

## Tech Stack

- React 18 + Vite
- Lucide React (icons)
- Google Fonts (Syne + DM Sans)
- Pure CSS animations

## Deploy to Netlify

```bash
npm run build
# Upload the dist/ folder to Netlify
```
